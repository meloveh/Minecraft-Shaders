# Meloveh Shaders — Minecraft 1.21.11

Custom shader pack for Minecraft **1.21.11** (Iris / OptiFine).

Author: **Meloveh (Dmitry Voronin)**

---

## About

A shader pack built for Minecraft 1.21.11. Focused on clean lighting, balanced performance, and a natural look — without overloading the GPU.

This is a solo project: code, shaders, testing, and optimization — all by one developer.

---

## Features

- Custom lighting and shadow system
- Optimized for Iris and OptiFine
- Support for Minecraft 1.21.11
- Clean water, sky, and atmosphere rendering
- Performance-friendly for mid-range GPUs
- Regular updates and bug fixes

---

## Requirements

- **Minecraft:** 1.21.11
- **Shader loader:** Iris 1.7+ or OptiFine HD U I7+
- **GPU:** OpenGL 4.5+ compatible
- **RAM:** 4 GB minimum, 8 GB recommended

---

## Installation

1. Install **Iris** or **OptiFine** for Minecraft 1.21.11.
2. Download the latest release of **Meloveh Shaders**.
3. Place the `.zip` file into `.minecraft/shaderpacks/`.
4. Launch Minecraft → Options → Video Settings → Shaders.
5. Select **Meloveh Shaders** from the list.
6. Apply and enjoy.

---

## Configuration

The shader pack includes an in-game settings menu (Iris/OptiFine shader options). You can adjust:

- Shadow quality
- Water waves and reflections
- Bloom and tonemapping
- Volumetric lighting
- Performance presets (Low / Medium / High / Ultra)
